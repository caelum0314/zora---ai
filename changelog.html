12 个编程技能 新增

  • code_search - 正则搜索代码，支持文件过滤
  • code_scan - 扫描类/函数/导入/TODO
  • file_read - 带行号读文件，支持分段读取
  • write_file - 写入/创建文件，支持追加模式
  • find_replace - 跨文件批量替换，默认 dry-run
  • edit - 打开系统默认编辑器
  • git_ops - Git 状态/差异/日志/分支
  • diff_review - 差异摘要和文件级统计
  • run_test - 运行测试，只展示失败用例
  • diagnose - 错误诊断和上下文分析
  • pip_ops - 包管理操作
  • web - DuckDuckGo 即时搜索
